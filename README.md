# Agent Lab

Workspace for agent guidance, skills, and related resources.

This repository changes often. Keep structure simple and practical.

## What You Find Here

- Agent rules in `AGENTS.md`
- Skills in `skills/`
- Supporting docs, scripts, templates, and assets
- Agents, scripts, configs, templates, and other artifacts as needed by active work

## Quick Navigation

1. Read `AGENTS.md` first.
2. Open the relevant entry point for your task (file, folder, script, or agent config).
3. For skills, start at `skills/<skill-name>/SKILL.md`.
4. Use local support folders only when needed.

## Editing Guidelines

- Keep content in English.
- Keep guidance short and direct.
- Prefer focused skills.
- Keep names simple and consistent (`kebab-case`).
- Avoid unnecessary complexity in structure and docs.
